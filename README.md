##  Airplane Crashes Data Cleaning

##  Project Overview

This project focuses on **data wrangling and data cleaning** using an airplane crashes dataset.

The aim of the project is to transform raw and potentially inconsistent data into a cleaner and more structured format that can be used for further **data analysis and visualization**.

The project is implemented in a **Jupyter Notebook** using Python.

---

##  Objectives

The main objectives of this project are to:

* Explore and understand the airplane crashes dataset.
* Identify missing or incomplete data.
* Detect and handle duplicate records.
* Correct inconsistent data formats.
* Convert columns into appropriate data types.
* Clean and standardize the dataset.
* Prepare the data for further analysis.

---

##  Data Wrangling Process

The notebook demonstrates several important data-wrangling techniques, including:

### 1. Data Inspection

The dataset is first examined to understand its structure, columns, data types, and general quality.

### 2. Handling Missing Values

Missing values are identified and handled appropriately depending on the affected variables.

### 3. Removing Duplicates

Duplicate records are checked to prevent repeated observations from affecting future analysis.

### 4. Data Type Conversion

Columns are converted into appropriate data types where necessary to make analysis easier and more accurate.

### 5. Data Standardization

Inconsistent values and formats are cleaned and standardized to improve the overall quality of the dataset.

### 6. Dataset Validation

The cleaned dataset is reviewed to confirm that the data-wrangling operations were successful.

The project demonstrates the importance of **data preparation before analysis**. Raw datasets often contain missing values, inconsistent formatting, incorrect data types, or duplicate records.

Through data wrangling, these issues can be identified and corrected so that the resulting dataset is more reliable and suitable for analysis.
